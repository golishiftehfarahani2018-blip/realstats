# خروجی‌های مشاهده اجرای واقعی

این فایل‌ها از اجرای نسخه اول در محیط مجازی تهیه شده‌اند و داده‌ها کاملاً ساختگی‌اند:

- execution-report.html: گزارش تصویری مستقل؛ پس از دانلود، با مرورگر باز کنید. این گزارش، خود برنامه تعاملی نیست.
- visual-walkthrough.mp4: فیلم مرور تصاویر صفحات واقعی اجرا؛ فیلم ضبط پیوسته تعامل کاربر نیست.

برای دریافت همه سورس و خروجی‌ها در GitHub از Code → Download ZIP استفاده کنید. هیچ رمز، کلید، .env یا dump بانک در این بسته وجود ندارد. راهنمای نصب و محدودیت‌های نسخه در docs/release-v1.md است.
