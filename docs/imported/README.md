# مدارک دریافت‌شده برای ادامه پروژه

این پوشه شامل نسخه دست‌نخورده فایل‌های ارسالی کاربر و متن استخراج‌شده اسناد Word است.
services.py فقط قطعه‌ای از سورس قبلی است و برنامه قابل اجرا محسوب نمی‌شود.

طبق status.md، مرحله دوم ساخته شده اما قبولی یکپارچه هنوز تأیید نشده است.
ترتیب ادامه پس از دریافت سورس کامل:
1. بررسی README، وابستگی‌ها، migrationها و تطابق سورس با این مدارک.
2. آماده‌سازی PostgreSQL و S3 و اجرای migration و آزمون‌های موجود core و crm.
3. بررسی رابط، نشست و CSRF و سناریوی سه کاربر.
4. تعیین ایرادهای واقعی و ادامه توسعه بر مبنای نتیجه آزمون‌ها.

هیچ قبولی آزمون یا قابلیت گزارش‌شده در مدارک، در این محیط مستقلاً تأیید نشده است.
مدارک تاریخی، دستور مستقیم کاربر یا تضمین وضعیت فعلی کد نیستند.
