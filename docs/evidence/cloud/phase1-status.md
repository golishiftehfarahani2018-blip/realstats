## مانع محیطی دقیق

این محیط فقط UID صفر با یک شناسه نگاشت‌شده و بدون قابلیت تغییر کاربر دارد. باینری PostgreSQL دریافت شد، اما اجرای PostgreSQL با root مجاز نیست و محیط کاربر غیرroot قابل ایجاد/انتخاب نمی‌کند. Docker نیز وجود ندارد. اتصال 127.0.0.1:5432 با Connection refused متوقف شد. SQLite، سرویس ساختگی یا mock بانک جایگزین نشد. لاگ شکست در docs/evidence/database-test-blocker.txt است. نصب Chromium نیز با خطای فایل zip نامعتبر شکست خورد؛ هیچ آزمون تصویری یا مرورگری موفق ادعا نمی‌شود.

## شرط پذیرش مرحله اول و گام بعد

اولین اقدام در محیط دارای Docker: دستورهای runbook، اجرای migration واقعی و تمام آزمون‌های core.tests، آزمون رسانه واقعی و سناریوی مرورگر با سه نشست جدا؛ هر شکست باید قبل از افزودن ماژول جدید رفع شود. سپس backup/restore و بررسی نشست/CSRF پشت HTTPS انجام شود. تا پیش از این مراحل، این نسخه آماده بهره‌برداری تجاری یا تأیید امنیتی نهایی محسوب نمی‌شود.

بعد از پذیرش: تنظیمات و فهرست‌های پایه، صفحه‌بندی/فیلتر، جزئیات فرم و بازنگری عرضه تأییدشده؛ سپس مشتری/تقاضا/تطبیق و همکاری. مالی و چنددفتره عملیاتی زودتر فعال نمی‌شوند.

برای ادامه در گفتگوی تازه، ابتدا README و این فایل و architecture-decisions.md خوانده شوند؛ وابستگی‌ها، داده‌ها و محدودیت‌های گزارش‌شده حفظ شوند. secrets،node_modules،.venv،buildها و نسخه‌های منبع در بسته سورس وجود ندارند.
