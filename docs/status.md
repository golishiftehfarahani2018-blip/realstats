# وضعیت نهایی تحویل نسخه اول

قابلیت‌های اصلی نسخه اول تک‌دفتره ساخته و در محیط مجازی اجرا شدند. راهنمای جامع، حدود دامنه و پیش‌نیازهای استفاده واقعی در [release-v1.md](release-v1.md) است؛ گزارش‌های قبلی در [status-history.md](status-history.md) نگهداری شده‌اند و وضعیت جاری را تعیین نمی‌کنند.

| بررسی نهایی | نتیجه |
|---|---|
| migration واقعی همه appها | موفق؛ .env و کلید قبلی حفظ شدند |
| PostgreSQL و S3 واقعی | ۸۸ آزمون موفق، بدون skip؛ در Python محیط و کانتینر |
| هم‌زمانی مالی | دو اتصال واقعی و یک نسخه: یک ثبت و یک تعارض |
| Django / drift migration / OpenAPI | موفق، schema بدون هشدار یا خطا |
| TypeScript / Next.js / Docker build | موفق |
| مرورگر مشتری و کارکنان | انتشار/رضایت، ثبت‌نام/علاقه‌مندی/درخواست، صندوق دفتر، مالی/سند معکوس/لغو، گزارش، دعوت، موافقت شخصی سهم و فیلتر موبایل/دسکتاپ موفق |
| HTTPS محلی | گواهی و hostname با trust صریح، DEBUG=0، کوکی Secure/HttpOnly، HSTS، CSRF و logout موفق |
| بازیابی بانک و رسانه | هر ۴۰ مدل با مقایسه کامل داده و رمزگشایی؛ هر دو bucket کپی و checksum رسانه آزمایشی و اتصال مدرک بررسی شد؛ منابع اصلی بازنویسی نشدند |
| بار کوچک محلی | ۱۰۰ درخواست، هم‌زمانی ۵، همه معتبر؛ گزارش تأخیر در evidence/release/local-load.txt |
| سرویس یادآور | worker اجراست؛ رویدادها یکتا و بدون متن خصوصی هستند |

شواهد فعلی در `docs/evidence/release` قرار دارند. قابلیت‌های اضافه‌شده: تنظیمات دفتر، فرم ویژگی‌ها و قیمت توافقی، بازنگری عرضه، رضایت و snapshot عمومی، تصاویر بازبینی‌شده، ویترین/جزئیات، حساب رمزدار مشتری و درخواست/علاقه‌مندی شخصی، دعوت یک‌بارمصرف مشاور، معامله و توافق نسخه‌دار/وصول/پرداخت/اختلاف/سند معکوس، گزارش/CSV و یادآور داخلی.

محدودیت‌های عملی: هیچ سرور/دامنه عمومی تهیه یا منتشر نشده است؛ TLS آزمایشی محلی کوتاه‌عمر است. OTP/پیامک، اتصال بانک/درگاه، چندشعبه عملیاتی، حسابداری کل، قرارداد خودکار و اپ بومی فعال نیستند و جزو تحویل نسخه اول نبودند. ورود مشتری با رمز است و تأیید تلفن ادعا نمی‌شود. ساعت پاسخ قابل تنظیم، تقویمی است؛ تقویم ساعت کاری پیاده نشده است. تطبیق فعلی سقف ۱۰۰۰ عرضه دارد. داده‌های نمونه کاملاً ساختگی‌اند و مبالغ آزمایشی، تعرفه یا سیاست واقعی دفتر نیستند. قواعد واقعی مالی و نگهداری داده پیش از استفاده واقعی باید تنظیم شوند.

همه فایل‌های حساس، کلیدهای TLS، رمزها، dumpها، node_modules و .venv از بسته سورس تحویل حذف می‌شوند. پیکربندی قابل استفاده مجدد محیط در پیش‌نویس تنظیمات ذخیره می‌شود؛ ذخیره پیش‌نویس، انتشار محیط یا استقرار عمومی محسوب نمی‌شود.
